# Point — идеи для минималистичного браузера

## Принцип

Не добавлять привычные «фичи браузера» ради количества. Добавлять тихие суперсилы, которые появляются только по запросу и не отвлекают от страницы.

## Уже заложено

- Минималистичный браузер: в центре всегда сама страница.
- Сайдбар открывается только тогда, когда он действительно нужен.
- Пользователь может просматривать страницы, создавать вкладки и поручать браузеру действия в интернете.

## Сохранённые страницы: не обычные закладки

### Идея

Сохранения не занимают место возле вкладок и не превращаются в постоянную полосу ссылок. Вместо отдельного менеджера закладок Point использует уже существующий концепт Spaces.

При первом запуске Point создаёт два Spaces:

- **Browse** — обычное пространство для текущего браузинга;
- **Saved** — спокойное пространство для сохранённых страниц.

Сохранённая страница хранится как вкладка в Saved, а не как запись в отдельной библиотеке закладок.

### Вход в сохранённое

- Saved открывается как обычный Space.
- Это осознанное действие: сохранённое не видно постоянно, но всегда легко найти.
- Не нужна отдельная панель или менеджер закладок.

### Что происходит при сохранении

- Сохранение подтверждается короткой, ненавязчивой анимацией.
- Никакая новая панель не появляется.
- Если пользователь сохраняет ссылку из предпросмотра, Point создаёт фоновую вкладку в Saved.
- Если пользователь сохраняет открытую страницу, Point переносит её вкладку в Saved, не переключая пользователя на этот Space.

### Saved вместо архива

Чтобы ссылки не становились кладбищем, Saved остаётся обычным, обозримым пространством вкладок:

- пользователь может открыть страницу, перенести её обратно в Browse или закрыть;
- не нужны папки, теги и отдельная система обслуживания закладок.

## Новая вкладка и поиск

- Нажатие `⌘T` открывает чистую новую вкладку с полем поиска.
- Пока пользователь ничего не ввёл, под полем показываются только несколько спокойных предложений из сохранённого — например, недавние или давно отложенные страницы.
- Не показывать полный список закладок на новой вкладке.
- Когда пользователь начинает печатать, единый список результатов может включать:
  - подсказки поисковой системы для текущего запроса;
  - поиск в интернете;
  - открытые вкладки;
  - сохранённые страницы;
  - историю.
- Сохранённые страницы отличает маленькая иконка, а не крупный отдельный раздел.

### Подсказки выбранной поисковой системы

- Подсказки должны зависеть от поисковой системы, которую выбрал пользователь, а не быть одинаковыми для всех.
- Сделать единый внутренний интерфейс: поисковая система получает текст, язык и регион, а Point получает нормализованный список подсказок.
- Отправлять запрос только после короткой паузы во вводе и отменять устаревший запрос, если пользователь уже напечатал дальше.
- Brave предоставляет официальный API подсказок.
- У Google нет отдельного публично документированного API для общих поисковых предсказаний: их Custom Search API возвращает результаты, а не обычные подсказки Google Search. Не строить продукт на неофициальном внутреннем endpoint.
- DuckDuckGo имеет доступный endpoint автодополнения, но его статус как стабильного публичного API нужно отдельно подтвердить перед использованием в продукте.

## Встроенный блокировщик рекламы и трекеров

### Суть

Point блокирует рекламу и распространённые трекеры сразу, без установки расширений. Это не отдельная «функция для управления», а естественная часть спокойного, сфокусированного браузинга: меньше шума на странице, быстрее загрузка, меньше лишних запросов.

### Реализация

- Использовать публичные WebKit Content Rule Lists в `WKWebView`.
- Правила компилируются из поддерживаемого списка фильтров и подключаются ко всем web views.
- Блокировать рекламные и трекинговые сетевые запросы до их загрузки, а также по возможности скрывать известные рекламные элементы.
- Список правил должен обновляться отдельно от выпусков приложения.

### Интерфейс

- Блокировщик включён по умолчанию и не занимает постоянное место в интерфейсе.
- Небольшой индикатор щита в сайдбаре или рядом с адресом может показать, что на странице что-то заблокировано.
- В меню индикатора — один главный контроль: «Отключить блокировку для этого сайта».
- Не строить отдельную сложную панель фильтров, счётчиков и настроек.

### Ограничения

- Не все объявления можно заблокировать: часть сайтов показывает рекламу с собственных доменов или создаёт её динамически.
- Некоторые страницы могут работать неправильно, поэтому per-site отключение необходимо с первой версии.
- Это правило-базовый блокировщик, а не полный движок расширений браузера.

## Предпросмотр ссылок по Shift

### Суть

Point даёт возможность посмотреть содержимое ссылки, не покидая текущую страницу и не открывая лишнюю вкладку. Это не происходит при каждом наведении: пользователь удерживает `Shift`, чтобы явно включить режим предпросмотра, затем наводит курсор на нужную ссылку.

Так жест остаётся намеренным, а обычный веб-сёрфинг — спокойным и лёгким.

### Поведение

1. Пользователь удерживает `Shift`.
2. Ссылки на странице становятся доступными для предпросмотра.
3. При наведении Point сразу показывает компактную карточку и начинает фоновую загрузку конкретной ссылки.
4. Карточка постепенно дополняется данными страницы.
5. В карточке доступна небольшая кнопка «Сохранить»: она добавляет ссылку в спокойное хранилище Later, не открывая отдельный менеджер закладок и не создавая новую вкладку.
6. Пользователь может открыть страницу полностью или закрыть предпросмотр, просто убрав курсор либо отпустив `Shift`.

Показанное ранее должно кэшироваться по URL: при повторном наведении карточка открывается сразу.

### Сохранить из предпросмотра

Кнопка «Сохранить» — это короткий путь из любопытства к намерению вернуться позже. Пользователь может сохранить статью, видео, товар или обычную страницу ещё до открытия ссылки.

- Кнопка остаётся маленькой и вторичной по отношению к открытию страницы.
- После сохранения она тихо меняет состояние, без баннеров и без появления панели закладок.
- Сохранение создаёт фоновую вкладку в Saved.
- Предпросмотр становится естественной точкой пополнения Saved, а не ещё одним местом, где нужно управлять ссылками.

### Статья

Для статьи предпросмотр превращается в небольшой Reader Preview:

- заголовок, домен, автор и дата, если они доступны;
- обложка;
- оценка времени чтения;
- основной текст без меню, рекламы и комментариев;
- возможность прокрутить первые фрагменты статьи прямо в карточке.

Reader Preview не требует ИИ. Point самостоятельно извлекает основной текст страницы лёгким алгоритмом. Если извлечение неуверенное, показывается обычная карточка, а не плохой «ридер».

### Видео

Для популярных видеосервисов используются отдельные адаптеры. Первая версия может поддерживать YouTube, VK Video и Instagram, а затем расширяться по реальному спросу.

- обложка, название, автор или канал, длительность;
- кнопка открытия страницы;
- при стабильной технической возможности — мини-плеер или короткое воспроизведение в карточке.

Автовоспроизведение не должно быть обязательным: оно может быть запрещено сайтом, требовать авторизацию или плохо работать из-за рекламы и защиты контента. В таких случаях остаётся качественная статичная карточка.

### Товары

Для популярных магазинов нужны такие же специальные адаптеры: Amazon, Ozon, Wildberries и другие сервисы, которые окажутся важны пользователям.

Карточка товара показывает:

- главное фото;
- название;
- актуальную цену и валюту;
- рейтинг и число отзывов, если они доступны;
- продавца, скидку или наличие — только если данные считываются надёжно;
- кнопку открытия товара в полной вкладке.

Это позволяет быстро сравнить несколько ссылок из поиска или чата, не открывая десяток вкладок.

### Универсальный вариант

Не каждая страница относится к статье, видео или товару. Для таких ссылок Point показывает нейтральную карточку: favicon, домен, заголовок, главное изображение и краткое описание из метаданных страницы.

### Технический принцип

Нельзя надёжно загрузить и разобрать новую страницу за несколько миллисекунд. Поэтому интерфейс должен работать поэтапно:

1. Мгновенно показать данные из кэша или URL.
2. После короткой намеренной задержки загрузить страницу в фоновом WebView.
3. Считать метаданные и признаки типа страницы.
4. Выбрать адаптер: статья, поддерживаемое видео, поддерживаемый магазин или универсальная карточка.
5. Сохранить безопасный результат в кэш для следующего предпросмотра.

### Границы первой версии

- Сначала: универсальная карточка и Reader Preview для статей.
- Затем: несколько наиболее важных видео- и торговых источников.
- Видеоплеер, сложное сравнение товаров и поддержка большого числа сайтов — только после проверки, что базовый предпросмотр действительно используют.

## Согласованный план

1. Saved Space: сохранённые страницы как вкладки в отдельном Space, с поиском по ним на новой вкладке.
2. Подсказки выбранной поисковой системы.
3. Предпросмотр ссылок по Shift: начать со статей, затем добавить ключевые видео- и торговые сайты.
4. Встроенный блокировщик рекламы и трекеров с отключением для конкретного сайта.
